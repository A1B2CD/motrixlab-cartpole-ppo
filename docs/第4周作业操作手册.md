## 1. 环境准备

### 1.1 确认 GPU 与依赖

```bash
cd ~/motrixlab-cartpole-ppo/motrixlab
uv run --no-sync python -c "import torch;print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_capability())"
```

期望输出：`2.7.0+cu128 True (12, 0)`。若显示 `+cpu`，重跑 `bash scripts/01_bootstrap.sh`。

### 1.2 装 ffmpeg（录屏必需）

```bash
sudo apt-get update -y && sudo apt-get install -y ffmpeg
ffmpeg -version | head -n 1
```

### 1.3 确认桌面 DISPLAY

```bash
echo $DISPLAY          # 期望 :20
xrandr | head -n 2     # 能打印分辨率即可
```

> 录屏用 `ffmpeg -f x11grab` 抓整个桌面。**回放时把其他窗口最小化**，让仿真窗口在屏幕中央，
> 这样 6 个视频的视角完全一致（作业要求"两组视角保持一致"）。

## 2. 三个 Demo 的运行与比较

### 2.1 Pendulum + Acrobot 训练与回放

```bash
cd ~/motrixlab-cartpole-ppo
bash scripts/24_demo_train_record.sh
```

脚本做的事（每个任务）：

1. `uv run scripts/train.py --env <env>` → 日志 `evidence/week4/20_train_<env>_demo.log`
2. 训练目录快照到 `motrixlab/runs/week4/<env>_demo/`（含 `checkpoints/best_agent.pt` 和 `events.out.tfevents.*`）
3. `play.py --num-envs 1 --seed 0` 回放一个完整回合，同时抓屏 → `evidence/week4/video/<env>_demo_seed0.mp4`

**截图点（对应评分项 2）：** 训练结束后终端最后的

```text
================================================================
耗时      : ...
RUN_DIR   : motrixlab/runs/pendulum/<时间戳>_PPO
SNAPSHOT  : motrixlab/runs/week4/pendulum_demo
BEST      : motrixlab/runs/week4/pendulum_demo/checkpoints/best_agent.pt
checkpoints:
  best_agent.pt  ...
tfevents  :
  events.out.tfevents....
================================================================
```

这一段同时给出「模型文件路径」（第 3 项）和「训练结束日志」（第 2 项）。

### 2.2 TensorBoard 曲线（每个任务一张）

```bash
cd ~/motrixlab-cartpole-ppo/motrixlab
uv run tensorboard --logdir runs/week4 --port 6006
```

浏览器打开 `http://127.0.0.1:6006`，左侧勾选 `pendulum_demo` / `acrobot_demo`，
看 `Episode / Total reward` 或 `Reward Total/...`，截图时**把任务名和曲线一起截进去**。

停止：终端 `Ctrl+C`。

### 2.3 Acrobot 太慢怎么办

Acrobot 默认 `timesteps=29000`、`num_envs=2048`，合计约 5940 万环境步。算力紧张时二选一：

```bash
# 方案 A：减少并行环境数（推荐，步数概念不变）
NUM_ENVS=256 bash scripts/24_demo_train_record.sh

# 方案 B：只跑 Pendulum，Acrobot 单独降规模
ENVS="pendulum" bash scripts/24_demo_train_record.sh
ENV=acrobot TAG=demo NUM_ENVS=256 bash scripts/20_train_env.sh
ENV=acrobot TAG=demo SEED=0 bash scripts/21_record_episode.sh
```

作业允许提前停止训练，**在文档里写清实际步数即可**（日志里 `total timesteps` 那行就是证据）。

## 6. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `play.py` 报 `No DISPLAY` | 在 KDE 桌面终端里跑，或 `export DISPLAY=:20` |
| 视频全黑 | 仿真窗口被其他窗口挡住 → 最小化其它窗口后重录 |
| 视频太短/太长 | `STEPS` 与环境不匹配：cartpole 1000、pendulum 400、acrobot 500 |
| `best_agent.pt` 不存在 | 训练被中断，用 `checkpoints/agent_*.pt` 里时间戳最大的那个 |
| `23_analyze_episode.py` 说找不到文件 | 路径要相对仓库根目录；先 `ls evidence/week4/csv/` |
| A/B 两组初始姿态不一致 | 回放漏了 `--seed`；`21_record_episode.sh` 已默认带 seed |
| 训练完 `git status` 显示 pendulum_np.py 被改 | 说明 B 组代码没恢复，跑 `bash scripts/22_pendulum_ab.sh` 的 train 阶段会自动 revert |
