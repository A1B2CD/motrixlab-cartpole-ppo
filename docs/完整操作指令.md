# 阶段 B：登录服务器 + 自检

## B1. 登录

Windows 自带 OpenSSH，直接开 PowerShell：

```powershell
ssh -i C:\path\to\key.pem ubuntu@<公网IP> -p <SSH端口>
```

只有密码时：

```powershell
ssh ubuntu@<公网IP> -p <SSH端口>
```

第一次连接会问 `Are you sure you want to continue connecting?`，输 `yes`。

## B2. 开一个 tmux（强烈建议）

SSH 断线不会杀掉训练和 TensorBoard：

```bash
tmux new -s rl
```

掉线后恢复：

```bash
tmux attach -t rl
```

## B3. 60 秒自检

```bash
nvidia-smi
cat /etc/os-release | head -3
df -h ~
curl -sS -o /dev/null -w "github %{http_code}\n" --max-time 15 https://github.com
curl -sS -o /dev/null -w "tuna   %{http_code}\n" --max-time 15 https://pypi.tuna.tsinghua.edu.cn/simple
```

判断：

| 看到什么 | 含义 |
| --- | --- |
| `nvidia-smi` 有表格，右上角 `CUDA Version: 12.x` | GPU 正常 |
| `CUDA Version: 12.0`（< 12.8） | 会装 CPU 版 torch，**正常**，CartPole 不需要 GPU |
| `github 200` | 能直接 clone |
| `github 000` | 用阶段 C 的方式 3 或 4 |
| `tuna 200` | 依赖能装 |

# 阶段 D：装环境

## D1. 一键装（推荐）

```bash
cd ~/motrixlab-cartpole-ppo
bash scripts/01_bootstrap.sh
```

它会做 5 件事：

1. `apt-get install`：`git curl build-essential xvfb x11-utils imagemagick mesa-vulkan-drivers libvulkan1 vulkan-tools`
2. 装 `uv`（astral.sh 不通时回落到 `pip install uv`）
3. `uv python install 3.10`
4. 按 `nvidia-smi` 的 CUDA 版本改写 `pyproject.toml` 里的 PyTorch 索引
5. `uv sync --all-packages --extra skrl-torch --python 3.10`

## D2. 强制指定轮子

```bash
TORCH_VARIANT=cpu   bash scripts/01_bootstrap.sh     # 强制 CPU 版
TORCH_VARIANT=cu128 bash scripts/01_bootstrap.sh     # 强制 CUDA 12.8 版
```

## D3. 验证

```bash
cd ~/motrixlab-cartpole-ppo/motrixlab
uv run --no-sync python -c "import torch,skrl,motrixsim;print(torch.__version__, torch.cuda.is_available(), skrl.__version__, motrixsim.__version__)"
```

CPU 机器预期：

```text
2.7.0+cpu False 1.4.3 0.7.0
```

GPU 机器预期：

```text

```

## F2. 在你自己的 Windows 上建隧道

**另开一个 PowerShell 窗口**（不要关掉服务器上那个）：

```powershell

```

- 这个窗口**没有任何输出**，是正常的

1. 点顶部 **SCALARS**

# 附录 B：报错对照表

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `bad interpreter: /usr/bin/env bash^M` | 脚本被 CRLF 污染 | `sed -i 's/\r$//' scripts/*.sh` |
| `ModuleNotFoundError: No module named 'motrix_rl'` | 工程在中文路径 | 换到 `/home/<user>/motrixlab-cartpole-ppo` |
| `uv sync` 卡在 `Resolving` | 网络 | 检查 `tuna` 连通性；重试或 `UV_HTTP_TIMEOUT=300` |
| `torch.cuda.is_available() == False` | 驱动 < CUDA 12.8 | 正常，CartPole 不需要 GPU |
| `failed to load an image` | 缺贴图 | 仓库只保留 CartPole 的 `motphys-ground.png`，其他环境缺资产属预期 |
| `tensorboard: command not found` | 不在 venv 里 | 用 `uv run tensorboard ...` |
| `GH008 ... unknown Git LFS objects` | 提交里混入 LFS 指针 | 本仓库已删除全部指针，不要从上游 zip 再拷资产进来 |
| `permission denied (publickey)` | deploy key 没配/没勾写权限 | `ssh -T git@github.com` 自查，或改用 PAT |
| `06_play_xvfb.sh` 截图失败 | 无 Vulkan/llvmpipe | 属正常，用 headless 证据 |
| `CUDA out of memory` | 环境数开太大 | `NUM_ENVS=32 bash scripts/02_train.sh` |
