| **域随机化** | ① 仅初始状态：`x, θ, ẋ, θ̇` 各 `±0.01` 均匀噪声；物理参数（质量/摩擦/阻尼/重力/gear）**未随机化**<br>② 每次 `reset()` 时逐环境采样 | ① 仅初始角度 `θ ~ U(-π,π)`；速度 0；物理参数**未随机化**<br>② 每次 `reset()`（回合结束自动重置时）重采样 | ① 仅两关节角度 `U(-π,π)`；速度 0；cfg 声明了 `reset_noise_scale=0.1` 但 `reset()` 未使用 → **速度噪声未实现**；物理参数**未随机化**<br>② 每次 `reset()` 重采样 | **共同点**：三者都只随机初始状态，都**没有**质量/摩擦/重力/电机增益等物理参数随机化。<br>**差异**：CartPole 是"小扰动"，另两个是"全姿态随机"。<br>来源：`cartpole_np.py:79-91`、`pendulum_np.py:107-109`、`acrobot_np.py:132-136`；未实现项的查找位置：各 `cfg.py`（只有 `reset_noise_scale` 字段）与各 `*.xml`（质量/摩擦/重力为固定值） |

> **补充：Acrobot 的目标点是固定的**。`acrobot.xml:31` 把 `target` site 写死在 world 坐标 `(0, 0, 4)`，
> `reset()`（`acrobot_np.py:128-143`）只随机两关节角，**不会移动目标**。两连杆各 1 m，
> 全垂下时 tip 离目标最远 2 m，所以这实际是一个「把两连杆甩到竖直、让 tip 够到正上方那颗 0.2 m 球」
> 的 swing-up 任务；单步 1.4 的满分要求 tip 长期停在那颗球里。

### A3 奖励（含 energy_reward）—— `pendulum_np.py:71-90`

```python
  71:         angle_wrapped = (angle + np.pi) % (2 * np.pi) - np.pi
  72:         ctrl = data.actuator_ctrls[:, 0]
  73:         # In this model, zero angle corresponds to the hanging-down position.
  74:         # Shift the target by pi to encourage the upright (inverted) posture.
  75:         upright = (1.0 + np.cos(angle_wrapped)) * 0.5
  76:         prev_ctrl = state.info.get("prev_ctrl", np.zeros_like(ctrl))
  77:         ctrl_delta = ctrl - prev_ctrl
  78:         vel_penalty = 0.2 * (ang_vel**2)
  79:         energy = 0.5 * ang_vel**2 + (1.0 - np.cos(angle_wrapped))
  80:         energy_target = 2.0
  81:         energy_reward = reward_utils.tolerance(
  82:             energy,
  83:             bounds=(energy_target, energy_target),
  84:             margin=2.0,
  85:             value_at_margin=0.1,
  86:             sigmoid="gaussian",
  87:         )
  88:         reward = (3.0 * upright + energy_reward - vel_penalty - 0.001 * ctrl**2 - 0.001 * ctrl_delta**2).astype(
  89:             np.float32
  90:         )
```
